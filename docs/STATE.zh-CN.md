## 持续有效的决策

- Unity 单进程模拟，纯 C# 核心不依赖 Unity/硬件；不为多 agent 协作拆运行时微服务。
- 梯子只要求有意义的交替拉动；暂停交替即停止继续获得高度。不把绳速符号用来切换真实阻力。
- 飞行为可调正常飞行近似；观察与转向分离，不宣称真实气动或训练有效性。
- 显示地形、AGL 与落地共用高度场。自动玩家只产生输入，不直接移动角色。
- Windows 优先；PC VR 保留方向，但未经执行的能力必须标注未验证。免费资源优先，付费另议。

每次变化同步本文件的状态；参数改动只修改代码并运行相关测试；新验收追加独立报告，不改写历史结果。聊天和外部讨论页是讨论资料，实施状态回写此仓库后才成为当前事实。
