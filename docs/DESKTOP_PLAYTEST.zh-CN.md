# 桌面试玩入口

打开本机 `game/Builds/Windows/ClimbDemo.exe`，不加命令行参数即为人工操作；不需要 PUMP、头显或 Unity Editor。若迁移到另一台电脑，需要复制整个 Windows 构建目录，不能只复制 exe。

## 建议的五分钟流程

1. 点击游戏窗口取得焦点。轮流按住 Q、松开，再按住 E、松开；每次给绳子一点回程时间。单侧重复不持续增加高度。
2. 到平台后，继续交替可爬得更高；按 Space 请求起飞，再松开 Q/E 等双绳回中。
3. 飞行时 Q 左转，E 右转，同时按下制动。鼠标右键拖动只改变观察方向，不参与转向。
4. Tab 切换目标。COURSE 是相对飞行方向的目标角度；Horizontal 是水平距离；AGL 是脚下离地高度。
5. 落地看距离与是否进入目标区。R 重试当前活动，C 回梯子，F 直接从高处练飞，P 暂停/继续。

切到其他窗口会暂停；回来后如提示 PAUSED，按 P 继续。人工模式保留长帧暂停保护，加载/系统卡顿时也可能需要按 P；本次启动修复针对自动试用，不会替人自动恢复游戏。关闭窗口退出。

优先记录三个感受：转弯是否过敏、共同制动是否容易理解、平台起飞是否自然。自动测试只能证明流程与数值行为，不能证明好玩或舒适。

当前是灰盒正常飞行近似：没有真实气动验证、复杂障碍碰撞或设备力反馈。树木和杆子是运动参照，不是碰撞障碍。
