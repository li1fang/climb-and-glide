## 发现并修复

1. OpenXR 构建前设置未加载。第一次按报错建议重建仍失败，随后查包源码，在 BuildPipeline 开始前通过公开的 `FeatureHelpers.RefreshFeatures` 初始化并保存设置，构建通过。
2. 运行时 `Shader.Find` 对应着色器未被打进包，实际截图全是洋红色。加入 Resources 中的明确着色器引用，重新运行确认颜色正常。
3. 首次渲染长帧触发输入间断保护，自动玩家停在起点。自动试用增加 3 s 预热，正式采样前重新初始化；正式试用期间仍保留长帧暂停规则。
4. 桌面同时显示两套状态文字。桌面保留屏幕 HUD，世界文字仅在 XR 路径显示。

第一次有画面的试用 `a1-20261107-071530` 未通过，观察到洋红色和暂停后主动结束；其日志保留，没有算作成功。最终修正后的版本已重新构建、真实运行并检查。

## 体验复盘与下一步

当前目标是验证循环，画面仍是基本几何：梯子、拉柄与落点可辨认，但场景缺少细节和运动参照。长时间爬梯换来不足 10 s 飞行仍是首要体验问题。

建议下一节点先做三项：

1. 增加起飞平台与落地区之间的地形高度差，保留较短的爬梯动作，给飞行更多时间。
2. 增加目标方向、距离与高度提示。当前自动路线并未瞄准目标，落地后目标还可能在身后；不能宣称已验证准确着陆玩法。
3. 缩小开发 HUD，增加可辨认的地面尺度与方向参照，再做桌面人工操作和 Quest 测试。

尚未验收：PC VR/手势/头显舒适性、PUMP、人工键鼠操作、复杂地形碰撞。XR 姿态代码仍有两条旧 API 弃用警告；构建日志的初始许可证握手警告随后恢复且最终构建成功，应保留记录，不描述为全程零警告。
